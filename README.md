# ДЗ №3

Небольшой проект из двух Docker-контейнеров, которые генерируют и анализируют
CSV-данные. Важная деталь: данные хранятся **локально на хосте**, а не внутри
контейнеров — папка `data/` пробрасывается в контейнер как том (`docker run -v`),
поэтому всё, что контейнер пишет в `/data`, остаётся на компьютере.

Тематика данных — **товары в магазине** (колонки `quantity`, `price`, `rating`,
`category`).

## Два выполнителя

- **Генератор** (`generator/`) — Python-скрипт `generate.py`, формирует
  `data/data.csv` (50 строк случайных данных). Образ на базе `python 3.12`.
- **Аналитик** (`reporter/`) — JS-скрипт `report.js`, читает `data/data.csv` и
  строит HTML-отчёт `data/report.html` (сводка по числовым и категориальным
  колонкам). Образ на базе `node:20-alpine`, зависимость `csv-parse` ставится
  внутри образа через `npm install`.

## Как запустить

```bash
./run.sh build_generator
./run.sh build_reporter
./run.sh run_generator      
./run.sh run_reporter       
```
Готовый отчёт — `data/report.html`, его как раз таки можно открыть в браузере.
